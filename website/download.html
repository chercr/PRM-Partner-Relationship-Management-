Docker 部署

克隆项目并设置 `.env` 后，通过 Docker Compose 构建和启动生产服务。

docker compose up -d --build查看完整步骤
需要 Excel 导入？ 导入文件需包含指定的「候选名单」工作表与表头；同步评分还需要「评估表」对应列。你可以 下载空白导入模板，替换其中的虚拟示例后再导入。

AFTER DOWNLOAD

下载后的三个动作

01

配置并启动

复制 `.env.example` 为 `.env`，设置管理员账号与强密码，然后使用 Docker Compose 启动。

02

创建业务档案

登录空工作区，新增伙伴与联系人；也可下载空白 Excel 模板，按指定工作表和表头整理后导入。

03

验证备份与更新流程

正式录入业务数据前，先验证手动备份、数据目录持久化和后续更新方式。
