# 渠成 · Channel OS

轻量、可自部署的通用渠道伙伴关系管理（PRM）系统，适用于渠道自拓、生态合作和伙伴运营团队。覆盖伙伴档案、多联系人、六维评估、跟进提醒、线索商机与贡献分析，形成完整的渠道经营闭环。

## 启动

### 本地开发

要求：Node.js 24+（使用内置 SQLite，无原生数据库依赖）。

```bash
npm install
npm run dev
```

打开 `http://localhost:5173`。Vite 页面会将 `/api` 转发至 `http://localhost:3001`。

### 生产模式

```bash
npm run build
npm start
```

打开 `http://localhost:3001`。

生产构建会生成 `dist/`（静态前端）与 `dist-server/index.cjs`（约 38KB 的单文件后端）。`npm start` 直接使用 Node.js 运行编译产物，不需要在生产环境安装 TypeScript、Vite、Playwright 或 tsx。

### Docker

```bash
docker compose up -d --build
```

打开 `http://localhost:3001`。数据库通过 `./data` 目录持久化。Docker 使用多阶段构建，运行镜像仅包含生产依赖和编译产物。

## 登录与初始化

- 默认管理员账号：`admin`
- 本地开发临时密码：`Qucheng@2026`
- 生产环境首次启动必须设置自己的 `ADMIN_PASSWORD`，不会使用公开默认值。

- 部署前建议复制 `.env.example` 为 `.env`，修改 `ADMIN_USERNAME` 和 `ADMIN_PASSWORD`。
- 系统始终从空工作区开始，不包含任何预置业务数据。
- 已配置 HTTPS 时，将 `COOKIE_SECURE=true`；纯 HTTP 内网部署保持 `false`。
- 系统设置中的「清空业务数据」需要再次验证管理员密码，并输入「清空」确认；该操作会删除全部业务数据和旧备份，保留账号。

## 已实现功能

- **工作台**：今日跟进、7 日计划、激活预警、转化漏斗、重点伙伴推进。
- **伙伴管理**：新增与编辑档案、组合筛选、优先级 / 总分 / 激活倒计时排序、分页、勾选导出。
- **联系人管理**：一个伙伴多位联系人、决策 / 商务 / 售前 / 交付角色、首要联系人、在职状态与联系方式。
- **任职履历**：离职保留历史，支持加入新伙伴并保留连续履历；原伙伴仍显示历史任职联系人，过往跟进和贡献关联不变。
- **六维评估**：固定权重、实时加权总分、A/B/C 分级、客户重叠度低于 3 分时 B 类封顶、未评完不出分。
- **状态流转**：未接触 → 已接触 → 已深聊 → 已谈合作框架 → 已签约 → 已激活，支持暂停与恢复。
- **签约激活**：代理商 60 天、实施服务商 90 天、IPD 咨询 120 天、专家不限期；到期前 14 天预警，逾期可确认暂停。
- **跟进留痕**：选择实际对接人，记录时间线、沟通方式、标签与下次跟进日期；报备线索 / 联合拜访 / 方案写入自动完成激活。
- **线索与商机**：登记客户线索、真实需求、预计金额与引荐人；信息完整可一键转商机，信息不足时引导补充；不进入后续销售阶段管理。
- **实际贡献分析**：按伙伴与渠道类型统计累计线索、已转商机、转化率、预计贡献金额及签约未产出伙伴。
- **界面偏好**：整体易读字号，系统设置支持标准 / 大号两档，偏好保存在当前浏览器。
- **Excel 导入**：识别「候选名单」与「评估表」，表头自动映射、导入预览、按公司名去重、同步评分。
- **数据看板**：自然月指标、转化漏斗、ABC 分布、六个月趋势、类型平均分与激活率。
- **渠道打法**：内置四类常见渠道合作策略、关注点与沟通建议。
- **数据安全**：SQLite 本地存储、运行期间每 24 小时自动备份、手动备份、CSV 导出。

## 初始数据

系统不包含原始名单、演示联系人或演示商机。可通过页面的 Excel 导入功能导入自己的候选名单，导入不会覆盖已有公司。清空业务数据后，系统会永久标记为已初始化。

## 数据与备份

- 数据库：`data/channel.db`
- 自动 / 手动备份：`data/backups/`
- CSV 导出：浏览器直接下载，包含六位评分、总分、分级、激活与跟进字段。

## 目录与缓存

- `src/`、`server/`：业务源码。
- `node_modules/`：本地开发和测试依赖，文件数量较多属于正常现象，不要删除后提交到版本库。
- `dist/`、`dist-server/`：可重新生成的生产构建产物。
- `.playwright/`：浏览器验收截图。
- `.npm-cache/`：安装缓存，已清理；不需要保留在项目目录。
- `data/`：SQLite 数据与备份，部署时应持久化。

## 技术栈

React · TypeScript · Vite · Express · Node.js SQLite · Recharts · SheetJS · Playwright

当前采用内部单租户、单管理员账号与账号密码认证模式。V1 不包含多用户权限、分润结算、线索报备工作流及企微 / 邮件集成。
